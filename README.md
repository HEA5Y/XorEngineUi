# XorEngineUi

**XorEngineUi** — кроссплатформенное графическое приложение на C++/Qt для многопоточного шифрования и дешифрования файлов с использованием побитовой операции XOR.

---

## 🚀 Возможности

* **XOR-шифрование:** Блочная обработка данных (по 64 бита) с кастомным HEX-ключом.
* **Режимы работы:** Одиночный запуск или автоматический фоновый мониторинг папки по таймеру.
* **Выбор файлов:** Фильтрация по расширениям и режим точечного выбора файлов «галочками» (выбор кэшируется и не сбрасывается таймером).
* **Конфликты имен:** Три стратегии при совпадении имен (Пропустить, Перезаписать, Счетчик в имени).
* **Безопасная многопоточность:** Вычисление в фоновом `QThread` (схема *Worker-Thread*). Интерфейс никогда не зависает.
* **Управление потоком:** Быстрый отклик на кнопки **Старт / Пауза / Стоп** благодаря связке `std::atomic`, `QMutex` и `QWaitCondition` (0% нагрузки на CPU на паузе).
* **Очистка:** Опция автоматического удаления оригиналов после успешной обработки.
